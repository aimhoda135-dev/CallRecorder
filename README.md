# 📱 تطبيق مسجل المكالمات للأندرويد

تطبيق لتسجيل المكالمات الصوتية وحفظها بصيغة عالية الجودة، مصمم خصيصاً للعمل خارج متجر جوجل بلاي لتخطي القيود البرمجية الحديثة.

## ✨ مميزات التطبيق المتوقعة:
- **تسجيل نقي:** يعتمد على الميكروفون العام للجهاز (MIC) لتسجيل الصوت.
- **حفظ تلقائي:** يتم حفظ المكالمات بصيغة MP4 الصوتية الخفيفة.
- **مذكرات المكالمة:** إمكانية إضافة ملاحظات نصية بعد انتهاء المكالمة.

## 🚀 طريقة التثبيت:
التطبيق يتم تحميله وتثبيته مباشرة كملف خارجي (APK) ولا يتطلب متجر جوجل بلاي.
